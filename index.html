Featured project

Predicting Lipophilicity from Molecular Structure

Lipophilicity shapes how a drug candidate is absorbed and distributed in the body, and measuring it for every molecule is slow. This project predicts it directly from a molecule's SMILES string, using the MoleculeNet Lipophilicity dataset of 4,200 experimentally measured logD values (octanol/water, pH 7.4). Models are tested on molecular scaffolds they never saw in training, which is a harder and more realistic test than a random split.

Input4,200 SMILESCC(=O)Oc1ccccc1C(=O)O
FeaturizeRDKit descriptors + Morgan fingerprints34 descriptors, 1,024 bits
ModelSVR vs. Extra Treesgrid search, scaffold-grouped CV
ResultTest RMSE 0.77R² 0.55 · baseline 1.16
